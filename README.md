# Gregory Lederer portfolio

Static GitHub Pages portfolio for basketball analytics work, experience, and selected projects.

## Structure

- `index.html` — primary portfolio
- `archive.html` — extended project archive
- `assets/css/` — shared visual system
- `assets/js/` — navigation and progressive enhancements
- `assets/images/` — local profile, project, and organization assets
- `assets/documents/reports/` — selected basketball reports
- `assets/documents/archive/` — older reports, visuals, school projects, and certificates

The site intentionally avoids a framework and build step. It can be previewed with any local static web server.
